# MartBox on Fire TV and Android

One app for Fire TV sticks, Android TVs and Android phones. It isn't in an
app store: install it from the MartBox release (the `MartBox-x.y.z.apk`
file), then sign in with the invite the server owner sends you.

## Fire TV

1. On the Fire TV: **Settings → My Fire TV → Developer options → Install
   unknown apps**, and turn it on for **Downloader** (install Downloader
   from the Amazon Appstore first if you don't have it). If you can't see
   Developer options, open **Settings → My Fire TV → About** and press
   select on the device name seven times.
2. Open **Downloader**, enter the APK's link from the latest MartBox
   release, and install it.
3. Open **MartBox**. The invite is long, so type it with the **Amazon Fire
   TV app on your phone**: open its keyboard while the invite box is
   selected and paste the invite there.

## Android phone

1. Download the APK from the latest MartBox release on the phone and open
   it. Android asks once to allow installing apps from your browser.
2. Open **MartBox** and tap **Scan QR code**, then point the phone at the
   QR code next to the invite on the server PC (**Settings → Users**). Or
   paste the invite the owner sent you.

## Updates

Install the new release's APK the same way; your sign-in and settings are
kept.
